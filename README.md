Hey, I’m **Anam Khan**, a second-year Computer Engineering student in Mumbai.

I like taking an idea from “what if this worked?” to something people can actually click, use, and react to. Some days that means building a frontend; other days it means untangling Java logic, learning a new tool, or figuring out why one tiny thing refuses to work.

I’m still exploring where I fit best across development and design. I’d rather build, test, and improve than pretend I’ve got every answer already.
